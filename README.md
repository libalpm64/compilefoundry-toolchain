# compilefoundry-toolchain

Browser-hosted Clang, LLD, and WASI sysroots for CompileFoundry.

## Outputs

- `clang.js`
- `clang.wasm`
- `lld.js`
- `lld.wasm`
- `sysroot-base.tar`
- `sysroot-threads.tar`
- `manifest.json`
- `SHA256SUMS`

## Versions

- LLVM commit `278c31bfb8ceb7ea17dbfd11a4fb21e6634af957`
- WASI SDK `34.0-rc.2+m`
- Emscripten SDK `6.0.8`

Run the Build and Release workflow manually or push a version tag.
